# Evidence Policy

Raw field logs, maps, videos, network details, host fingerprints, and credentials are not committed to this public snapshot.

The repository records reviewed conclusions in `remote-inventory-2026-08-04.md`,
`validation-2026-08-04.md`, and cryptographic hashes in `SHA256SUMS`. Large
videos should be attached to a release or stored with Git LFS only after privacy
review.

## Published demo

The reviewed project demo is published as the `audio-test01.mp4` asset on the
`v0.2.0-candidate.1` prerelease. SHA256:
`c2a8dc1c3b187205f5efb5392562f0e1d41d5c58575656ca2cd10c18d8494e88`.
It is demonstration media, not acceptance evidence for production deployment of
the 0.08 m candidate.
