# Evidence Policy

Raw field logs, maps, videos, network details, host fingerprints, and credentials are not committed to this public snapshot.

The repository records reviewed conclusions in `remote-inventory-2026-08-04.md`,
`validation-2026-08-04.md`, `validation-2026-08-25.md`, and cryptographic hashes
in `SHA256SUMS`. Large
videos should be attached to a release or stored with Git LFS only after privacy
review.

## Published demo

The reviewed project demo is published as the `audio-test01.mp4` asset on the
`v0.3.0-candidate.1` prerelease. The file is 65,499,360 bytes. SHA256:
`ccec8554a6a1a68f3af2f2e81b3ef410870907cda46a57e78dfed2872839d5c1`.
It is demonstration media, not production authorization or acceptance evidence
for the current 0.80 m candidate.
