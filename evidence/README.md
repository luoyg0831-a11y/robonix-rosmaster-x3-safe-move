# Evidence Policy

Raw field logs, maps, videos, network details, host fingerprints, and credentials are not committed to this public snapshot.

The repository records only reviewed conclusions in `docs/validation-status.md` and cryptographic hashes in `SHA256SUMS`. After SSH recovery, sanitized machine-readable summaries may be added under this directory. Large videos should be attached to a GitHub release or stored with Git LFS only after privacy review.
