# 项目说明

本项目把 ROSMASTER X3 的 ROS1 `move_base` 封装成带人工确认的移动流程。程序先在
车头前方搜索候选点，用户选择编号后再检查一次 AMCL、全局代价地图和路径。目标信息
显示出来后，用户必须输入“确认执行”，程序才会进行最后一次检查并发布导航目标。

## 主要限制

- 候选半径为 `0.80 m` 到 `0.10 m`，由远到近检查。
- 只返回通过检查的最远一档，最多 5 个候选点。
- 候选方向限制在前方 `±30°`。
- 执行阶段只接受当前候选会话签发的一次性令牌，不接受外部坐标。
- 项目代码不直接发布 `/cmd_vel`。
- odom 和 AMCL 参数上限为 `1.00 m`；使用该上限时在 `0.90 m` 触发取消。

准备接口的 `0.93 m` 距离上限、候选搜索的 `0.80 m` 上限和预览后的 `0.03 m`
位置变化限制是三项独立检查。`0.93 m` 不会把候选搜索范围扩大到 0.93 m。
